# Heavy PWA Transformation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Transform Adventures of Trishu into a heavy PWA with 100% offline gameplay, automated chunk precaching, native Screen Wake Lock, kid-friendly install prompt & iOS guidance, update notification toasts, and rich manifest shortcuts.

**Architecture:** Build-time precache generation script scans Vite's `dist/assets/` and injects exact chunk hashes into `dist/sw.js` with multi-tier caching (cache-first for chunks, network-first for navigation, stale-while-revalidate for assets). A dedicated singleton `PwaManager` manages Screen Wake Lock, `beforeinstallprompt`, iOS Safari standalone detection, network status, and update lifecycle, wired to tactile Trishu-styled HUD controls and install/update modals.

**Tech Stack:** TypeScript, React 19, Vite 6, Service Worker API, Cache Storage API, Screen Wake Lock API, Canvas 2D icon generator.

**Spec:** `docs/superpowers/specs/2026-09-04-heavy-pwa-design.md`

## Global Constraints
- Every source file in `src/` must remain strictly under 500 lines of code (Tier 4 quality gate).
- Zero external CDN dependencies in `index.html` and `manifest.json` (Tier 4 quality gate).
- Zero new runtime npm dependencies; zero npm install conflicts with React 19 and Vite 6.
- 100% strict TypeScript with zero `any` leaks.
- All 32 existing tests must continue to pass in `< 1.0s` via `npm test`.
